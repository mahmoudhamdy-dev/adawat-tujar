# أدوات التجار (Adawat Tujar)

منظومة أدوات ويب مجانية فورية باللغة العربية للتجار وأصحاب المتاجر الإلكترونية (تعمل مباشرة داخل المتصفح بدون تسجيل وبدون رفع البيانات لأي خادم).

- الموقع الرسمي: https://adawattujar.com

## الأدوات المتاحة

- [صانع الفواتير وقوالب الطباعة](https://adawattujar.com/tools/invoice-maker) — فواتير مبيعات وعروض أسعار للطباعة الحرارية وA4.
- [صانع بوليصة الشحن](https://adawattujar.com/tools/shipping-waybill) — بوالص شحن مع استيراد إكسيل وباركود التتبع.
- [استوديو الباركود وبطاقات الأسعار](https://adawattujar.com/tools/barcode-studio) — طباعة ملصقات 38×25 و50×25 و40×30 مم وA4.
- [صانع سند قبض](https://adawattujar.com/tools/receipt-voucher) و[سند صرف](https://adawattujar.com/tools/payment-voucher) — مع التفقيط العربي التلقائي.
- [صانع عرض سعر](https://adawattujar.com/tools/quotation) — عروض أسعار رسمية بصيغة PDF.
- [حاسبة الضريبة 15%](https://adawattujar.com/tools/vat-15-calculator) و[استخراج الضريبة](https://adawattujar.com/tools/extract-vat).
- [صانع باركود QR](https://adawattujar.com/tools/qr-generator) و[باركود واي فاي](https://adawattujar.com/tools/wifi-qr-code).
- [توقيع وختم ملفات PDF](https://adawattujar.com/tools/pdf-sign-stamp).
- [ضبط مقاسات صور المتاجر](https://adawattujar.com/tools/image-resizer) و[مقاس صور سلة](https://adawattujar.com/tools/salla-image-size).
